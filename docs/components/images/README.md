# Component artwork

These stills are CloudAtlas's approved component art, framed as 1024-by-1024 PNGs on a dark background, with no text in the image. Each file is the illustration for the matching spec sheet in this folder's parent. They are not in-game screenshots, and they are not a claim that every pictured motion is implemented. Captions on the spec sheets name the state that is shown.

| File | Component | State shown |
|---|---|---|
| `multiplexer.png` | Multiplexor | Lane select red, blue tint, powered on |
| `dialor.png` | Dialor | Dial at 32, on, blue tint |
| `via.png` | Via | Straight single, blue, strength 64 |
| `watchor.png` | Watchor | Family iso, blue, firing |
| `bitor.png` | Bitor | AND, blue, on |
| `pushor.png` | Pushor | Retracted, blue, powered (extension is still open) |
| `swivelor.png` | Swivelor | Detent 0, home (turning is not implemented) |
| `resin.png` | Resin | Item (the pot). Not a block |
